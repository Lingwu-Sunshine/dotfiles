* 一、放置配置文件
1. 在 ~i3~ 此文件夹的位置( =~/.config/wallpaper= )配置信息为:
   #+BEGIN_SRC yaml
     exec --no-startup-id feh --randomize --bg-fill ~/.config/wallpaper
   #+END_SRC
2. 将字体文件夹 ~fonts~ 移至到 ~$HOME/.local/share~ 目录下，然后刷新字体库，命令为 ~fc-cache~ 或者 ~fc-cache -vf~
3. 文件夹 ~fish~ 为 ~fish~ 的配置文件，应放到 =~/.config/= 目录下面

   - 使用如下命令查看系统信息
     #+begin_src shell
       ❯ ls -l /sys/class/power_supply/
       total 0
       lrwxrwxrwx 1 root root 0 Jan 19 08:31 ADP1 -> ../../devices/LNXSYSTM:00/ACPI0003:00/power_supply/ADP1/
       lrwxrwxrwx 1 root root 0 Jan 19 08:31 BAT1 -> ../../devices/LNXSYSTM:00/LNXSYBUS:00/PNP0C0A:00/power_supply/BAT1/
     #+end_src
   - 更改 =modules.ini= 文件中的电量接口
     #+begin_src yaml
       [module/battery]
       type = internal/battery

       ; This is useful in case the battery never reports 100% charge
       full-at = 99

       ; Use the following command to list batteries and adapters:
       ; $ ls -1 /sys/class/power_supply/
       battery = BAT1 #改这行
       adapter = ADP1 #还有这行
     #+end_src
